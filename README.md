# Hearta · Espiral

**A D&D 5.5e character sheet manager**, originally created for a personal RPG campaign set in the world of Hearta.

What started as a personal project grew into a feature-rich character sheet, designed to make character management easier and keep everything in one place.

## Features

- **Auto-save:** Character data is saved automatically in the browser.
- **Mana system:** An alternative resource system for spellcasting.
- **Flexible AC:** Support for different armor class calculations.
- **Automatic XP and leveling:** Track experience and character progression.
- **Spell compendium:** Integrated spell reference.
- **Inventory management:** Manage equipment, items, and carrying capacity.
- **Usage dice:** A resource management mechanic inspired by *The Black Hack*.
- **Proficiencies:** Tool and craft proficiencies.

## How to use

Hearta is a standalone HTML file. No installation or server is required.

1. Download `heartaespiral.html` from this repository.
2. Open the file in your browser.
3. Create or manage your character!

The sheet can be used offline. Character data is stored locally in your browser, so clearing browser data may erase your saved character. Keep backups when necessary.

*Some external resources, such as fonts, may require an internet connection.*

## Development

This project was developed primarily with the assistance of AI tools. Its concept, requirements, features, and overall direction were shaped around the needs of my own RPG campaign.
